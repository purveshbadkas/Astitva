# ASTITVA

ASTITVA is a web-based face recognition and criminal detection system built using Python and Flask. The system allows users to upload or draw sketches, capture live images through a webcam, and automatically match them against a database of known criminals using facial recognition.

The project is designed for use in law enforcement or research environments where matching a sketch or real-time image to known identities is essential.

---

# Features

- User registration and login system
- Upload or draw facial sketches using pre-made components
- Real-time face detection using webcam
- Face matching using facial embeddings
- Criminal database with image storage and CSV log
- Simple web interface using HTML, CSS, and JavaScript

---

# Technologies Used

- Python (Flask Framework)
- OpenCV for webcam and image capture
- face_recognition library for face embeddings and matching
- SQLite and CSV for data storage
- HTML, CSS, and JavaScript for frontend
- Git and GitHub for version control
